USER MUST CREATE A USERNAME WITH AN UNDERSCORE
PASSWORD WITH AT LEAST 8 CHARACTERS, CAPITAL LETTER, CONTAIN NUMBER AND SPECIAL CHARACTER
CELLPHONE NUMBER WITH INTERNATIONAL COUNTRY CODE
IF THE REGISTRATION REQUIREMENTS ARE MET THE USER WILL BE ALLOWD TO LOGIN .
ON LOGIN SECTION THE CODE WILL CHECK IF THE REGISTRATION DETAILS MATCH WITH LOGIN DETAILS.
